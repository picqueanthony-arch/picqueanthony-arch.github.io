Sans root

Données

Les valeurs de tes API (météo, Bitcoin, NASA…) en cartes.

Dans Gateway, ouvre une source qui répond en JSON et touche « Choisir les données à afficher ». Dante appelle l'adresse, liste ce que la réponse contient (nombres, textes, images) et tu coches ce que tu veux voir : un prix, une température, l'image du jour… Aucune API n'est connue d'avance : tout ce qui répond en JSON, en CSV, en XML ou en texte simple marche.

Chaque source devient une carte dans ce module : la valeur principale avec la courbe de son historique, les autres valeurs en lignes, le texte et l'image. Tu choisis la fréquence (de « en direct » à 24 h) et où part la clé d'API : en-tête Authorization (Bearer), en-tête de ton choix, paramètre d'adresse, identifiant:mot de passe (Basic) ou à la place de {key} dans l'adresse ; tu peux ajouter d'autres en-têtes. Si une API demande d'attendre (« trop d'appels »), Dante attend ; si elle ne répond plus, il la relit de moins en moins souvent.

Le menu ☰ ouvre un panneau latéral (comme dans Fichiers) : tes cartes y sont rangées par thème (météo, finance, espace, développeurs…, et « Mes API » pour celles que tu as branchées à la main). Touche un thème pour n'en voir que les cartes ; « Tout » les montre toutes, avec un titre par thème.

Si « Données » est dans ton dock, son icône pulse à chaque fois qu'une valeur change, et un point rouge reste dessus jusqu'à ta prochaine visite de la page. Sur l'accueil, Dante relit ce qui est échu toutes les minutes (le « en direct » ne descend pas sous 5 min ici).

Dante ne contacte que les sources de ta liste, à la fréquence choisie, y compris en arrière-plan. Les valeurs et l'historique restent sur le téléphone. Si une API change de forme, la carte le dit au lieu d'afficher une valeur fausse.

Astuces

Un nombre écrit entre guillemets dans la réponse est lu comme un texte : il s'affiche, mais sans courbe.

L'image haute définition d'une API est lourde : prends plutôt la version normale.
