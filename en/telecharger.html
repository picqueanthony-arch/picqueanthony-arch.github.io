Install

  1. Download the APK file.
  2. Open it and allow installs from this source when Android asks.
  3. Open Dante OS and choose it as your home screen.

Updating: install the new version on top, your settings stay. Before a big change: Desktop ▸ Customize ▸ Backup ▸ Export.
